## 🌟 주요 핵심 기능

### 1. 🚀 월보고 전체 4단계 연속 자동 라이브 기입 (원클릭)
* **[1단계] 세입세출표 시트 (1번 시트)**: NMIS `회계 > 결산관리 > 세입세출표` 47개 과목의 금월세입액/금월세출액 수치를 실시간 파싱하여 엑셀 수식 및 합계 수치 정밀 자동 기입
* **[2단계] 회원현황 시트 (2번 시트)**: NMIS `회원 > 회원현황 및 통계 > 월회원현황보고` 공부상 업소수, 실존 업소수, 금월 회원수 자동 기입 및 검수
* **[3단계] 월별 회원현황 및 세입실적 시트 (4번 시트)**: 회비/가입금 수입실적, CMS/직접수금 징수건수, 가입 5대 지표 수치 통합 기입
* **[4단계] 직원회원가입실적 시트 (5번 시트)**: 담당 직원(신희관 부장) 및 계 행에 해당 월 가입실적 지표 자동 입력

### 2. 📨 통합 발송대장 5건 순차 자동 등록
* NMIS `관리자 > 문서대장관리 > 발송대장관리` (`admin/document/ship/list`) 메뉴로 이동 후 5개 문서 자동 추가 및 기입:
  1. `총무 120` | `{보고월} 보고` | `전라북도특별자치도지회` | `Mail`
  2. `총무 120` | `{보고월} 직원 개인별 회비, 가입금 징수실적 현황` | `전라북도특별자치도지회` | `Mail`
  3. `총무 120` | `{보고월} 직원 개인별 회원 가입실적` | `전라북도특별자치도지회` | `Mail`
  4. `정경 650` | `{보고월} 음식문화개선운동 추진실적` | `전라북도특별자치도지회` | `Mail`
  5. `총무 120` | `{보고월} 자율지도 추진실적보고 보고({q}/4)` | `전라북도특별자치도지회` | `Mail`
* **분기 (`{q}/4`) 자동 계산**: 작성 보고월(예: 7월말 ➔ `(3/4)`)에 따라 4분기 값을 자동 산출하여 적용.
* **발송일자 포맷팅**: 8자리 날짜 포맷(`YYYYMMDD`) 세팅을 통해 달력 칸 옆 텍스트 박스까지 완벽 기입.

### 3. 📋 전표 거래내역 연속 자동 등록
* 통장/카드 거래내역 엑셀 파일을 불러와 회비/가입금, 급여/상여 등 전표 유형을 자동 분류하고 NMIS 웹에 순차 등록.

### 4. 📥 네이버 메일 → 접수대장 → HWP/PDF 자동화
* 사이드바의 **`접수대장`** 탭에서 조회 기간을 지정하고 `전체 발신자` 또는 특정 발신자를 선택해 검색합니다.
* 네이버 메일 IMAP을 읽기 전용으로 검색해 `.hwp`/`.hwpx`/`.pdf` 첨부파일을 내려받고 처리 목록을 표시합니다.
* 저장 파일명은 `원본파일명_YYYYMMDD.확장자` 형식으로 수신일을 붙입니다. 같은 날짜에 이름이 중복될 때만 `_2`, `_3`을 추가합니다.
* 같은 발신자가 같은 이름으로 파일을 재발송한 경우 가장 최근 메일의 첨부파일 한 건만 다운로드·접수합니다.
* HWP/PDF의 `시행 : 경영800-1 (2026. 1. 2.)` 형식을 읽어 `분류번호=경영800-1`, `문서일자=2026.01.02`로 분리 입력합니다.
* 메일 조회 직후 본문을 빠르게 검사해 정상적인 `시행 : 분류번호(문서일자)`와 `접수 :` 칸이 모두 있는 문서만 목록에 표시합니다. 등록 직전에도 같은 조건을 다시 확인하므로 접수칸 없는 문서는 NMIS에 저장되지 않습니다. 글자 정보가 없는 스캔 이미지 PDF는 OCR 처리 후 사용할 수 있습니다.
* 접수일자는 네이버 메일 수신일, 문서일자는 HWP/PDF 시행란의 날짜로 각각 입력합니다. 전북특별자치도지회는 발신자 `전북특별자치도지회`·내외구분 `내부`, 그 밖의 메일은 실제 보낸사람 이름·내외구분 `외부`로 설정하고 수신자는 `진안군지부`로 입력합니다.
* NMIS 저장 후 자동 생성된 접수번호는 HWP 접수란에 `15 (2026.04.13)` 형식으로 입력합니다.
* 선택한 문서를 NMIS `관리자 > 문서대장관리 > 접수대장관리`에 저장한 뒤 발급된 접수번호를 HWP의 `접수번호` 누름틀, 자리표시자 또는 `접수` 표 칸에 입력합니다.
* 원본 파일은 변경하지 않습니다. HWP는 접수번호를 입력한 복사본, PDF는 원본과 동일한 복사본을 `접수완료` 폴더에 저장하며 메일 ID와 첨부파일 해시로 중복 접수를 방지합니다.
* 네이버 메일은 **IMAP 사용 설정 + 2단계 인증 + 애플리케이션 비밀번호**가 필요합니다. 로그인 성공 후 앱 비밀번호는 Windows DPAPI로 암호화되어 같은 Windows 사용자 계정에서만 자동 복원됩니다.
* 한컴 공식 `FilePathCheckerModuleExample.dll`을 현재 사용자 계정에 자동 등록해 HWP를 여러 건 처리할 때 파일 접근 `허용` 창이 반복되지 않게 합니다.
* 목록의 `선택` 체크 열을 클릭하거나 위아래로 드래그해 실행 범위를 정할 수 있으며 `전체 선택`·`전체 해제`와 기존 Ctrl/Shift 다중 선택도 지원합니다.

### 5. 💳 통장이체 엑셀 → 월회비 입금 자동등록
* 사이드바의 **`회비 입금등록`** 탭에서 `거래일자 / 성명·상호 / 금액` 엑셀을 불러와 날짜가 빠른 순서대로 처리합니다.
* 거래일자의 월을 NMIS 기준년월로 설정하고 대표자를 조회한 뒤 `월회비` 행에 당월입금액과 입금일자를 입력·선택하여 저장합니다.
* `가입금`만 있거나 `월회비` 행이 없는 사람은 저장하지 않고 다음 항목을 계속 처리하며, 전체 작업 후 별도 명단과 건수를 안내합니다.

### 6. 💎 럭셔리 다크 모드 UI & 무음 실행
* **CustomTkinter** 기반 딥 바이올렛 & 네온 그린 액센트 디자인.
* DOS 검은 창이 뜨지 않는 배경 무음 실행 (`run_ui.vbs`).
* 사용자 계정 정보 자동 기억 및 보안 관리.

## 📦 다운로드 및 설치 방법 (Installation)

### Windows 원클릭 자동 설치 (추천)

저장소를 ZIP으로 내려받아 압축을 푼 뒤 **`설치하기.bat`**를 더블클릭합니다. 한글 파일명이 깨지는 환경에서는 동일한 설치 파일인 **`install.bat`**를 실행하면 됩니다.

설치 파일이 다음 작업을 자동으로 수행합니다.

* Python 3.10 이상이 없으면 Python 3.12 설치
* Google Chrome이 없으면 Chrome 설치
* 프로젝트 전용 `.venv` 가상환경 생성
* `requirements.txt`의 Python 패키지 전체 설치 및 검증
* 바탕화면에 **`통합 자동화 시스템`** 바로가기 생성

Microsoft Excel과 한컴오피스 한글은 유료 프로그램이므로 자동 설치 대상이 아닙니다. 월보고/Excel COM 기능에는 Microsoft Excel, HWP 접수번호 입력에는 한컴오피스 한글이 각각 설치되어 있어야 합니다. 네이버 메일 앱 비밀번호는 Windows 사용자별 DPAPI로 암호화되므로 새 PC에서 한 번 다시 입력해야 합니다.

### 1. Repository 클론 및 폴더 이동
```bash
git clone https://github.com/shinhuigwan/nmis-integrated-automation.git "통합 자동화 시스템"
cd "통합 자동화 시스템"
```

### 2. 가상환경 생성 및 필요 라이브러리 설치
```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

## 🚀 실행 방법 (Usage)

### 방법 A. 프로그램 바로 실행 (추천 - DOS 창 없음)
프로그램 폴더 내 **`통합 자동화 시스템 실행.vbs`** (또는 `run_ui.vbs`) 파일을 더블 클릭하여 실행합니다. (검은색 명령 프롬프트 창 없이 깔끔하게 실행됩니다.)

### 방법 B. 배치 파일 실행
**`통합 자동화 시스템 실행.bat`** (또는 `run_ui.bat`) 파일을 더블 클릭하여 실행합니다.

## 📖 상세 사용 방법 가이드

1. **`🌐 Chrome 연결 열기` 버튼 클릭**:
   * 사이드바 하단의 **`🚀 Chrome 연결 열기`** 버튼을 누르면 NMIS 로그인 페이지가 열립니다.
   * 프로그램이 로그인 및 회계 메뉴 접속을 자동으로 진행합니다.

2. **`📁 [1] 월보고 기본 설정` 확인**:
   * **월보고 엑셀 파일**: 바탕화면의 `26년 월보고.xls` 파일이 기본 선택됩니다. (필요 시 `파일 선택`으로 변경)
   * **작성 기준년월**: 작성할 전표/결산 년월 (예: `2026-07`)
   * **발송일자 / 보고월**: 발송대장에 기입될 일자 및 보고월 구분 (예: `2026.08.05` / `7월말`)

3. **원클릭 자동 실행**:
   * **`🚀 월보고 전체 4단계 자동 작성`**: 세입세출표부터 직원가입실적까지 4개 시트를 한 번에 라이브 기입합니다.
   * **`📨 통합 발송대장 5건 자동 등록`**: 발송대장 관리 화면으로 자동 이동하여 5개 문서 행을 연속 기입합니다.
