# ⚡ NMIS (통합) 전표 & 월보고 자동화 시스템 (Modern Dark Edition)

> **한국외식업중앙회 통합 회계 및 회원 관리 시스템 (NMIS)** 과 **월보고 엑셀 파일** 간의 데이터를 실시간으로 수집·기입·검수하고, **발송대장 5건 자동 등록** 및 **전표 자동 기입**을 지원하는 럭셔리 다크 모드 자동화 프로그램입니다.

## 🌟 주요 핵심 기능

### 1. 🚀 월보고 전체 4단계 연속 자동 라이브 기입 (원클릭)
* **[1단계] 세입세출표 시트 (1번 시트)**: NMIS `회계 > 결산관리 > 세입세출표` 47개 과목의 금월세입액/금월세출액 수치를 실시간 파싱하여 엑셀 수식 및 합계 수치 정밀 자동 기입
* **[2단계] 회원현황 시트 (2번 시트)**: NMIS `회원 > 회원현황 및 통계 > 월회원현황보고` 공부상 업소수, 실존 업소수, 금월 회원수 자동 기입 및 검수
* **[3단계] 월별 회원현황 및 세입실적 시트 (4번 시트)**: 회비/가입금 수입실적, CMS/직접수금 징수건수, 가입 5대 지표 수치 통합 기입
* **[4단계] 직원회원가입실적 시트 (5번 시트)**: 담당 직원(신희관 부장) 및 계 행에 해당 월 가입실적 지표 자동 입력

### 2. 📨 통합 발송대장 5건 순차 자동 등록
* NMIS `관리자 > 문서대장관리 > 발송대장관리` (`admin/document/ship/list`) 메뉴로 이동 후 5개 문서 자동 추가 및 기입:
  1. `총무 120` | `{보고월} 보고` | `전라북도특별자치도지회` | `Mail`
  2. `총무 120` | `{보고월} 직원 개인별 회비, 가입금 징수실적 현황` | `전라북도특별자치도지회` | `Mail`
  3. `총무 120` | `{보고월} 직원 개인별 회원 가입실적` | `전라북도특별자치도지회` | `Mail`
  4. `정경 650` | `{보고월} 음식문화개선운동 추진실적` | `전라북도특별자치도지회` | `Mail`
  5. `총무 120` | `{보고월} 자율지도 추진실적보고 보고({q}/4)` | `전라북도특별자치도지회` | `Mail`
* **분기 (`{q}/4`) 자동 계산**: 작성 보고월(예: 7월말 ➔ `(3/4)`)에 따라 4분기 값을 자동 산출하여 적용.
* **발송일자 포맷팅**: 8자리 날짜 포맷(`YYYYMMDD`) 세팅을 통해 달력 칸 옆 텍스트 박스까지 완벽 기입.

### 3. 📋 전표 거래내역 연속 자동 등록
* 통장/카드 거래내역 엑셀 파일을 불러와 회비/가입금, 급여/상여 등 전표 유형을 자동 분류하고 NMIS 웹에 순차 등록.

### 4. 💎 럭셔리 다크 모드 UI & 무음 실행
* **CustomTkinter** 기반 딥 바이올렛 & 네온 그린 액센트 디자인.
* DOS 검은 창이 뜨지 않는 배경 무음 실행 (`run_ui.vbs`).
* 사용자 계정 정보 자동 기억 및 보안 관리.

## 📦 다운로드 및 설치 방법 (Installation)

### 1. Repository 클론 및 폴더 이동
```bash
git clone https://github.com/shinhuigwan/nmis-integrated-automation.git "통합 자동화 시스템"
cd "통합 자동화 시스템"
```

### 2. 가상환경 생성 및 필요 라이브러리 설치
```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

## 🚀 실행 방법 (Usage)

### 방법 A. 프로그램 바로 실행 (추천 - DOS 창 없음)
프로그램 폴더 내 **`통합 자동화 시스템 실행.vbs`** (또는 `run_ui.vbs`) 파일을 더블 클릭하여 실행합니다. (검은색 명령 프롬프트 창 없이 깔끔하게 실행됩니다.)

### 방법 B. 배치 파일 실행
**`통합 자동화 시스템 실행.bat`** (또는 `run_ui.bat`) 파일을 더블 클릭하여 실행합니다.

## 📖 상세 사용 방법 가이드

1. **`🌐 Chrome 연결 열기` 버튼 클릭**:
   * 사이드바 하단의 **`🚀 Chrome 연결 열기`** 버튼을 누르면 NMIS 로그인 페이지가 열립니다.
   * 프로그램이 로그인 및 회계 메뉴 접속을 자동으로 진행합니다.

2. **`📁 [1] 월보고 기본 설정` 확인**:
   * **월보고 엑셀 파일**: 바탕화면의 `26년 월보고.xls` 파일이 기본 선택됩니다. (필요 시 `파일 선택`으로 변경)
   * **작성 기준년월**: 작성할 전표/결산 년월 (예: `2026-07`)
   * **발송일자 / 보고월**: 발송대장에 기입될 일자 및 보고월 구분 (예: `2026.08.05` / `7월말`)

3. **원클릭 자동 실행**:
   * **`🚀 월보고 전체 4단계 자동 작성`**: 세입세출표부터 직원가입실적까지 4개 시트를 한 번에 라이브 기입합니다.
   * **`📨 통합 발송대장 5건 자동 등록`**: 발송대장 관리 화면으로 자동 이동하여 5개 문서 행을 연속 기입합니다.
