NMIS 통합 자동화 시스템 — Windows 10/11 64비트 배포판

1. ZIP 파일을 바탕화면이나 문서 폴더에 완전히 압축 해제합니다.
2. NMIS-Automation.exe를 실행합니다. Python과 Python 패키지는 설치할 필요가 없습니다.
3. Chrome이 없거나 바탕화면 바로가기가 필요하면 Setup.bat를 실행합니다.
   Google 공식 Chrome 설치 파일이 installers 폴더에 동봉되어 있습니다.
   Chrome 설치와 NMIS 접속에는 인터넷 연결이 필요합니다.
4. 계정 및 시스템 설정에서 본인 NMIS 계정을 저장하고 사용할 계정을 체크합니다.
5. Chrome 연결 열기를 누르고 로그인할 계정을 선택합니다.
6. 다음 버전부터는 프로그램 왼쪽 '업데이트 확인'을 누르세요.
   새 버전을 다운로드·검증한 뒤 자동 교체하고 재실행합니다.
   settings.json과 data 폴더의 계정·명단·날짜·접수 이력은 유지합니다.

월보고 작성 등 Excel COM 기능에는 Microsoft Excel이 필요합니다.
HWP 접수 처리에는 한컴오피스 한글이 필요합니다.
두 유료 프로그램의 설치 파일과 라이선스는 포함하지 않습니다.
음식과사람 배포 기능은 Excel/한글 없이도 사용할 수 있습니다.

주의사항
- _internal 폴더를 삭제하거나 exe 파일만 따로 옮기지 마세요.
- ZIP 안에서 직접 실행하지 말고 반드시 압축을 먼저 해제하세요.
- 사용자 계정·비밀번호·메일·배포 명단은 배포판에 포함되지 않습니다.
- 새 PC에서는 계정과 네이버 앱 비밀번호를 새로 입력하세요.
- 비밀번호는 해당 PC/Windows 사용자에게 귀속된 DPAPI 암호문으로 저장됩니다.
- 설정은 settings.json, 계정·명단·접수 이력은 data 폴더에 저장됩니다.
- 업데이트할 때 기존 settings.json과 data 폴더를 보존하세요.
- 실행 오류는 프로그램 폴더의 startup.log를 확인하세요.
